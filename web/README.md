# ForeSight PML — Holiday Audit Web

Static React SPA version of the Holiday Audit Tool.
Compatible with Hostinger shared hosting and any static file server.

## Structure

```
holidays/web/
  export_to_json.py     ← Convert parquet → JSON (run once with Python)
  package.json
  vite.config.js
  index.html
  src/
    main.jsx
    App.jsx
    constants.js
    dataStore.js
    components/
      Calendar.jsx
      Charts.jsx          ← MainChart, WeeklyContextChart, ClusterChart
      FeatureTable.jsx
      MetaBadges.jsx
      Sidebar.jsx
  public/
    data/
      audit_data.json     ← Generated by export_to_json.py
      audit_labels.json   ← Generated by export_to_json.py
```

    ## Initial setup

    ### 1. Export data to JSON (requires Python + parquet)

    From the project root:

```bash
python holidays/web/export_to_json.py
```

This generates:
- `holidays/web/public/data/audit_data.json`
- `holidays/web/public/data/audit_labels.json`

### 2. Install Node.js dependencies

```bash
cd holidays/web
npm install
```

### 3. Local development

```bash
npm run dev
```

Open http://localhost:5173

### 4. Production build (Hostinger)

```bash
npm run build
```

Upload the contents of `dist/` to your hosting environment (Hostinger File Manager or FTP).

## Label persistence

In the web version, edited labels are stored in **browser localStorage**.
To export them permanently, use these buttons:
- **Export CSV** — downloads `audit_labels_DATE.csv`
- **Export Nixtla** — downloads Nixtla long format for the ML pipeline
