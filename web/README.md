# Holiday Audit Web

Static React SPA version of the Holiday Audit tool.
Compatible with static hosting and local Vite development.

## Structure

```text
web/
  export_to_json.py     <- Convert Parquet audit outputs to JSON
  package.json
  vite.config.js
  index.html
  src/
    main.jsx
    App.jsx
    constants.js
    dataStore.js
    components/
      Calendar.jsx
      Charts.jsx
      FeatureTable.jsx
      MetaBadges.jsx
      Sidebar.jsx
  public/
    data/
      audit_data.json    <- Generated by export_to_json.py
      audit_labels.json  <- Generated by export_to_json.py
```

`public/data/` is created on demand the first time you export JSON.

## Initial setup

### 1. Export data to JSON

From the repository root:

```bash
python web/export_to_json.py
```

This generates:
- `web/public/data/audit_data.json`
- `web/public/data/audit_labels.json`

### 2. Install Node.js dependencies

```bash
cd web
npm install
```

### 3. Local development

```bash
npm run dev
```

Open http://localhost:5173

### 4. Production build

```bash
npm run build
```

Upload the contents of `dist/` to your static hosting environment.

## Label persistence

Edited labels are stored in browser localStorage.
To export them permanently, use these buttons:
- **Export CSV** - downloads `audit_labels_DATE.csv`
- **Export Nixtla** - downloads Nixtla long format for the ML pipeline
